# MoTech Smart Meter Platform - Phase 1 Architecture

This branch introduces the foundation for a scalable feature-based frontend architecture.

## Structure

- features/ - business modules
- components/ - reusable UI components
- layouts/ - application layouts
- routes/ - routing configuration
- services/ - API and external integrations
- store/ - application state management
- hooks/ - reusable React hooks
- types/ - shared TypeScript definitions
- utils/ - shared utilities

Phase 1 focuses on organization and scalability while preserving existing functionality.
